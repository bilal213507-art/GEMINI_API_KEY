# Bilal Abid AI - GitHub & Netlify Repository

This repository contains the complete source code for **Bilal Abid AI**, configured for deployment on **Netlify** using Netlify Serverless Functions and the updated **`gemini-3.8-flash`** model.

## Folder Structure
```text
├── functions/
│   └── api.js          # Netlify Serverless Function (Express + Gemini API)
├── public/
│   └── index.html      # Frontend UI
├── .env.example        # Environment variable template
├── .gitignore          # Keeps secrets and node_modules out of Git
├── netlify.toml        # Netlify build & serverless function config
└── package.json        # Dependencies
```
